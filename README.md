# Song Note

ブラウザだけで使える、シンプルな作曲ノートです。

## 機能
- 曲タイトル
- キー・BPM・拍子
- 曲構成
- コード進行
- 歌詞メモ
- 音源・ボイスメモ添付
- 自動保存
- 曲一覧・検索
- 曲の削除
- スマホ対応

## 使い方
1. `index.html` をブラウザで開く
2. 「新しい曲」を押す
3. 入力内容はブラウザ内に自動保存されます

## GitHub Pagesで公開
1. Settings → Pages を開く
2. Branchを `main`、フォルダを `/root` に設定

※ データは端末のブラウザ内に保存されます。端末やブラウザが変わると共有されません。
